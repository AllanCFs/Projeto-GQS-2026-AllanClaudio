# Teste de Usabilidade

**Metodologia:** Observação de uso via console/interface.
**Participantes:** 3 potenciais adotantes.
**Tarefas:** 1. Encontrar a lista de cães disponíveis. 2. Tentar realizar a adoção.
**Conclusões:**
* Participante 1: Achou o fluxo simples, mas sugeriu filtros por idade. (Ação: Implementado filtro no relatório).
* Participante 2: Teve dúvida sobre o termo "Em Análise". (Ação: Mensagem do console atualizada para ser mais clara).
* Participante 3: Fluxo de cadastro foi rápido e intuitivo.
